# CypherLink Frontend

Vite + React + TypeScript + Tailwind frontend.

## Run
```bash
npm install
npm run dev
```
Open `http://localhost:5173`.

## Included
- Public browse-first landing/home
- Login only for participation features
- Culture-first homepage
- Intentional TikTok-style clips section
- Open/venue cypher cards and lifecycle
- Optional QR check-in and profile QR
- Project rooms with focused UI
- Living scene map
- Intent-first messaging
- Community sessions / musicians for a cause
- Search, notifications, settings
- Axios refresh-token interceptor placeholder
- Socket.IO client placeholder

## Env
```env
VITE_API_URL=http://localhost:3001/api
VITE_WS_URL=http://localhost:3001
```
